### Fixed

- The backend CI job is a real gate again. `pytest` was wrapped in
  `|| echo "Tests skipped (dependencies not installed)"` with `continue-on-error: true`, so
  the check reported success no matter what the suite did. It now fails the build on any
  test failure.
- Four genuine test defects that the no-op gate had been hiding, each reproduced before
  it was fixed:
  - `test_v2_api` posted without an authenticated user, so dispatch crashed on `user.id`
    and answered 500 instead of exercising adapter resolution — the fixture now supplies
    an authenticated user;
  - `test_wan22_route_cleanup` built a path set from `route.path`, which FastAPI 0.147
    no longer exposes for mounted routers (`AttributeError`) — replaced by a helper that
    tolerates entries without a path;
  - `test_storage_client` presigned tests left the real `_minio_public` client in place,
    so they talked to the live MinIO (`S3Error: InvalidAccessKeyId`) instead of the mock;
  - `test_api_v1::test_get_credits` only passed depending on import order, because
    `api_v1` binds `get_credit_manager` at import time; the fixture now patches the
    binding where it is used.

### Changed

- The backend job no longer carries configuration copied from another project
  (`DATABASE_URL=…cryptotrader_test`, `BITFINEX_API_KEY/SECRET`, `PAPER_TRADING`, the
  `pg_isready` step), and no longer installs dependencies with `--no-deps … || echo`.
- Job scope is explicit: GPU and integration suites are out of scope for the PR gate
  (`--ignore=tests/gpu --ignore=tests/manual -m "not gpu and not integration"`); they need
  a live ComfyUI/MinIO/Supabase and belong on the dedicated runner.
- `coverage.xml` / `.coverage` are generated by the job and are now gitignored.
