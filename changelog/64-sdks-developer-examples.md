### Added
- Python SDK package (`sdk/python/`) with sync and async clients, typed models, error handling, webhook verification
- JavaScript/TypeScript SDK (`sdk/javascript/`) using native fetch, full TypeScript types, webhook signature verification
- Discord bot example (`sdk/examples/discord_bot.py`) with `/imagine`, `/video`, `/animate`, `/credits` commands
- Postman collection (`sdk/postman_collection.json`) with all API v1 endpoints, webhook management, auto-saved job IDs
- Exported OpenAPI 3.1 spec (`sdk/openapi.json`) filtered to public endpoints (12 paths, 11 schemas)
- SDK overview README with quick start guide and API reference
